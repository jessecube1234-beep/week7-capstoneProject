# week7-capstoneProject
WeatherNow is a simple weather app I built using HTML, CSS, Bootstrap, and JavaScript. It uses the Open-Meteo API to show current weather information for any city the user searches. The app updates the page with the city name, temperature, humidity, wind speed, and precipitation.

##Features

1. Lets users search for a city and choose between metric or imperial units

2. Gets live weather data using Axios and async/await

3. Has form validation and dynamic updates

##Tools Used

HTML, CSS, Bootstrap, JavaScript, Axios, and the Open-Meteo Weather and Geo APIs.

Notes

I tested the APIs in Postman before connecting it to my app. This project shows how I used API calls, form validation, Bootstrap components, and DOM manipulation all together.
